# Components List

Project: Automatic Gate Detection System

1. ESP32 Development Board - 1
2. HC-SR04 Ultrasonic Sensor - 1
3. IR Obstacle Sensor - 1
4. 1k Ohm Resistor - 1
5. 2k Ohm Resistor - 1
6. Breadboard - 1
7. Jumper Wires - 1 set
8. USB Cable - 1

Software:
1. Arduino IDE
2. ESP32 Board Package
3. Serial Monitor

Output:
GATE OPEN
GATE CLOSED

Gate operation is simulated through Serial Monitor.
No physical motor or servo is used.
