
## Project Overview

Car Detection and Automatic Gate Simulation System using ESP32.

## Components

- ESP32 Development Board
- HC-SR04 Ultrasonic Sensor
- IR Obstacle Sensor
- Resistors
- Breadboard and Jumper Wires

## Working Principle

1. Ultrasonic sensor measures the distance of an approaching car.
2. IR sensor detects the vehicle.
3. ESP32 processes sensor signals.
4. Gate operation is simulated through Serial Monitor.

## Gate Status Sequence

1. GATE OPEN
2. CAR IS CROSSING
3. GATE CLOSED

## Software

- Arduino IDE
- ESP32 Board Package
- Serial Monitor

## Communication

Serial Monitor Baud Rate: 115200
