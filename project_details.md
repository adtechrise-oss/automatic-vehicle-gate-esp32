
# Project Details

## Project Name
Automatic Vehicle Gate Detection System

## Objective
To detect vehicles approaching and crossing a gate using ESP32 and sensors.

## Working Sequence

1. Detect approaching vehicle.
2. Display GATE OPEN.
3. Display CAR IS CROSSING.
4. Display GATE CLOSED after the vehicle crosses.

## Sensors Used
- HC-SR04 Ultrasonic Sensor
- IR Obstacle Sensor

## Controller
ESP32

## Output
Serial Monitor

## Communication
115200 Baud Rate

## Current Development Stage
Sensor-based gate simulation.
